One-time setup

Connect Supabase to use the admin.

The storefront is running from cakes.json. To edit cakes from this page, add your Supabase project URL and anon key to site.config.js, then run supabase/setup.sql in the SQL editor. 

supabase: {
  url: "https://YOUR-PROJECT.supabase.co",
  anonKey: "YOUR-ANON-KEY",
  table: "cakes",
  bucket: "cake-photos",
}

Full instructions are in README.md → Admin setup.
