# Fonts

Self-hosted Latin WOFF2 subsets, originally served by Google Fonts. Self-hosting removes a third-party request from the critical path and avoids sending visitor IPs to a font CDN.

| File | Family | Weights | Upstream |
| --- | --- | --- | --- |
| `fraunces-latin.woff2` | Fraunces | 300–700 | https://github.com/undercasetype/Fraunces |
| `fraunces-italic-latin.woff2` | Fraunces Italic | 300–700 | https://github.com/undercasetype/Fraunces |
| `dm-sans-latin.woff2` | DM Sans | 300–700 | https://github.com/googlefonts/dm-fonts |
| `space-grotesk-latin.woff2` | Space Grotesk | 300–700 | https://github.com/floriankarsten/space-grotesk |

All three families are licensed under the **SIL Open Font License 1.1**:
https://openfontlicense.org/open-font-license-official-text/

The subsets cover Latin characters. Tamil copy falls back to the device’s Tamil font, so no Tamil glyph file is shipped.
